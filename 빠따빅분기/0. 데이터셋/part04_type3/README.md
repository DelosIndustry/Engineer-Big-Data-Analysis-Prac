# PART 04 작업형3 통계 데이터셋

이 폴더의 데이터는 빅데이터분석기사 실기 작업형3 원고와 실습을 위해 새로 만든 가상 데이터입니다.

## 포함 데이터셋

- `one_sample_ttest_study_time/study_time.csv`: 단일표본 t-검정
- `independent_ttest_app_time/app_task_time.csv`: 독립표본 t-검정 및 등분산성 확인
- `paired_ttest_training_score/training_score.csv`: 대응표본 t-검정
- `anova_support_channel_rating/support_rating.csv`: 일원분산분석
- `chisquare_device_plan/device_plan.csv`: 카이제곱 독립성 검정
- `correlation_regression_ad_orders/ad_orders.csv`: 상관분석 및 단순회귀
- `logistic_regression_trial_signup/trial_signup.csv`: 로지스틱 회귀

## 저작권 안전 기준

- 참고서 데이터셋을 사용하지 않았습니다.
- 참고서 컬럼명과 문제 상황을 복제하지 않았습니다.
- 모든 행 데이터는 난수 기반으로 생성한 가상값입니다.
- 내부 정답 파일은 저자/검수용 패키지에만 포함합니다.
